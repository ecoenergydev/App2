# EcoEmissionBot 
It is a bot, which calculate NOx (1.4) 
It allows you to enter the results of oxygen and NO emission measurements 
and obtain the result of converting nitrogen oxide emissions to NOx (1.4).

## Requirements

* Java 21 & Spring Boot 4
* Gradle > 8.14

## Run 
1. Go to the link and wakeup bot: https://hex-t-bot.onrender.com
2. Open @EcoEmissionBot
3. Enter "/start"
4. Enter two numbers separated by a space:
O2, % NOx, ppm
Example: 6 57
